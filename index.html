Auto-publish with Vercel

Push to main or run the workflow manually to deploy.

  1. Add VERCEL_TOKEN, VERCEL_ORG_ID, and VERCEL_PROJECT_ID.
  2. Push to main or choose “Deploy to Vercel” in GitHub Actions.
  3. Vercel builds, publishes, and returns the production URL.
